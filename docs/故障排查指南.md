## 启动问题

### 修改器无法启动
**症状**：双击 EXE 无反应或报错

**排查步骤**：
1. 确认系统为 Windows 10/11 64位
2. 安装 [Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe)
3. 安装 [.NET Runtime](https://dotnet.microsoft.com/download)
4. 检查杀毒软件是否误删文件
5. 以管理员身份运行
6. 查看是否有错误日志：`%LOCALAPPDATA%\woldvein_trainer\logs\`

### 启动后白屏/卡死
**症状**：修改器窗口空白或无响应

**排查步骤**：
1. 等待 5-10 秒（首次启动较慢）
2. 关闭杀毒软件后重试
3. 删除配置文件后重启：`%LOCALAPPDATA%\woldvein_trainer\config.json`
4. 确认显卡驱动为最新

## 注入问题

### DLL 注入失败 - OpenProcess 错误码 5
**原因**：权限不足

**解决**：
1. 右键修改器 → 以管理员身份运行
2. 确认游戏不是以更高权限运行

### DLL 注入失败 - 错误码 87
**原因**：参数错误，通常是 PID 无效

**解决**：
1. 确认游戏已完全启动（不是启动器界面）
2. 等待游戏进入主菜单后再注入
3. 重新点击「检测游戏」按钮

### DLL 注入后游戏崩溃
**原因**：DLL 与游戏版本不兼容

**解决**：
1. 确认游戏版本受支持
2. 检查是否有其他修改器/注入器冲突
3. 验证 DLL 文件完整性（重新下载）

### 提示 DLL 已注入但功能无效
**原因**：DLL 注入成功但 Lua hook 未生效

**解决**：
1. 等待 3-5 秒后再使用功能
2. 进入游戏存档（不是主菜单）后再使用
3. 查看日志是否有 Lua 执行错误
4. 尝试卸载后重新注入

## 功能问题

### 资源增加无效果
**排查步骤**：
1. 确认 DLL 已注入（主页显示「已注入」）
2. 确认已进入游戏存档（不是主菜单）
3. 查看日志面板是否有错误
4. 尝试切换场景后再查看资源
5. 确认资源 ID 正确（不同版本可能有差异）

### 创造模式开启后无效果
**排查步骤**：
1. 确认创造模式的子选项已勾选
2. 创造模式需要在开启后重新进入场景生效
3. 部分功能需要重新加载存档
4. 查看日志确认 Lua 执行成功

### 品阶晋升失败
**排查步骤**：
1. 确认当前品阶未达到上限（14级）
2. 品阶晋升需要逐次执行，不要连续快速点击
3. 查看日志中的错误信息
4. 尝试先备份存档再操作

### 时间控制无效
**排查步骤**：
1. 确认游戏内时间在流动（不是暂停状态）
2. 时间加速可能与游戏内速度叠加
3. 时间暂停后需要手动恢复
4. 部分过场动画会忽略时间控制

## 游戏崩溃

### 使用功能后立即崩溃
**紧急处理**：
1. 不要重新注入，先恢复存档备份
2. 查看崩溃时的日志
3. 记录是哪个功能导致的崩溃

**常见原因**：
- 资源数值超出游戏上限（已通过输入校验预防）
- 在错误的游戏状态下使用功能（如过场动画中）
- 与其他 MOD 冲突
- 游戏版本不匹配

### 游戏运行一段时间后崩溃
**排查步骤**：
1. 减少同时开启的功能数量
2. 关闭创造模式中不需要的子选项
3. 检查游戏日志中的错误堆栈
4. 确认不是游戏本身的 bug

### 崩溃后存档损坏
**恢复步骤**：
1. 不要覆盖存档
2. 打开存档页 → 恢复最近的备份
3. 如果没有备份，检查 Steam 云存档是否有旧版本
4. 使用存档修复工具（如存档页的修复功能）

## 性能问题

### 修改器导致游戏卡顿
**排查步骤**：
1. 关闭不需要的功能（特别是创造模式的子选项）
2. 降低监控页的刷新频率
3. 关闭 Overlay（如果启用）
4. 确认不是游戏本身的性能问题

### 修改器自身卡顿
**排查步骤**：
1. 关闭日志自动滚动
2. 减少日志保留条数
3. 清理旧备份和日志
4. 确认 CPU/内存占用正常

### 内存占用持续增长
**排查步骤**：
1. 这是正常现象（功能缓存），通常上限在 100MB 以内
2. 重启修改器可释放内存
3. 如果超过 500MB，可能是内存泄漏，请反馈

## Overlay 问题

### Overlay 不显示
**排查步骤**：
1. 确认 Overlay DLL 已注入（区别于主 DLL）
2. 按 INSERT 键切换显示
3. 确认游戏使用 DX11（当前仅支持 DX11）
4. 关闭其他 Overlay 软件（Steam Overlay、Discord、MSI Afterburner）
5. 游戏无边框窗口模式下兼容性更好

### Overlay 显示但无法点击
**原因**：输入焦点未切换到 Overlay

**解决**：
1. 点击 Overlay 区域获取焦点
2. 部分游戏需要按住特定键才能操作 Overlay
3. 检查 Overlay 的输入拦截设置

### Overlay 导致画面闪烁
**解决**：
1. 降低 Overlay 渲染帧率
2. 关闭透明效果
3. 更新显卡驱动
4. 切换游戏为无边框窗口模式

## 热键问题

### 热键完全不生效
**排查步骤**：
1. 确认 DLL 已注入
2. 确认热键功能已启用（设置页 → 启用热键）
3. 检查热键是否与其他软件冲突
4. 尝试修改为其他热键组合
5. 以管理员身份运行（全局热键需要更高权限）

### 热键偶尔失效
**原因**：热键防抖机制

**说明**：
- 普通功能防抖 200ms
- 高危功能防抖 500ms
- 连续快速按键会被忽略
- 这是正常保护机制，防止误触

### 热键触发错误功能
**解决**：
1. 在设置页检查热键映射
2. 恢复默认热键配置
3. 删除配置文件后重新设置

## 存档问题

### 存档备份失败
**排查步骤**：
1. 确认存档目录存在且可访问
2. 确认磁盘空间充足
3. 确认游戏未锁定存档文件（关闭游戏后备份更可靠）
4. 查看日志中的具体错误

### 存档恢复后游戏报错
**排查步骤**：
1. 确认备份的存档版本与当前游戏版本匹配
2. 恢复后验证存档文件完整性
3. 尝试恢复更早的备份
4. 检查是否需要删除 Steam 云存档缓存

### 存档修改后无法加载
**原因**：存档校验失败

**解决**：
1. 恢复修改前的备份
2. 不要手动编辑存档文件（使用修改器的存档编辑器）
3. 确认修改的数值在合理范围内

## 更新问题

### 自动更新失败
**排查步骤**：
1. 检查网络连接
2. 确认 GitHub 可访问（可能需要代理）
3. 手动下载最新版本
4. 以管理员身份运行（更新需要写权限）

### 更新后功能失效
**排查步骤**：
1. 确认配置文件已迁移
2. 重新注入 DLL
3. 检查版本兼容性
4. 查看更新日志是否有破坏性变更

### 回滚到旧版本
**步骤**：
1. 关闭修改器
2. 删除新版本文件
3. 从备份目录恢复旧版本（`backup_时间戳/`）
4. 或从 GitHub 下载旧版本

## 收集诊断信息

提交 Bug 时请附带以下信息：

1. **修改器版本**：设置页 → 关于
2. **游戏版本**：Steam 库 → 游戏属性 → 更新
3. **系统信息**：监控页 → 一键系统诊断 → 导出
4. **日志文件**：日志页 → 导出日志
5. **复现步骤**：详细描述操作顺序
6. **截图**：错误提示或异常现象
