# woldvein Trainer 用户手册

《平野孤鸿》(Ballads of Hongye) 游戏修改器 v0.4.6

---

## 快速上手

### 1. 启动修改器
- 双击 `woldvein_trainer.exe` 启动
- 首次启动会自动检测游戏安装路径
- 如果检测失败，手动设置游戏路径（设置页 → 游戏路径）

### 2. 启动游戏
- 通过 Steam 启动《平野孤鸿》
- 等待游戏进入主菜单或存档

### 3. 注入 DLL
- 点击主页的「注入 DLL」按钮
- 等待提示「DLL 注入成功」
- 注入成功后所有功能可用

### 4. 使用功能
- **主页**：资源修改、时间控制、创造模式
- **创造页**：一键全开、解锁功能
- **工具页**：高级工具、品阶晋升、灾害控制
- **存档页**：存档备份、恢复、清理
- **监控页**：进程状态、系统诊断
- **设置页**：热键配置、主题、游戏路径

## 功能说明

### 资源修改
- 支持 8 种资源：金钱、粮食、木材、石材、铁矿、人口、知名度、幸福度
- 每种资源可自定义增加数量
- 「一键全部资源 +100万」快速增加所有资源
- 「资源归零」清空所有资源（需二次确认）

### 创造模式
- 满级鸿业：城市品阶直接拉满
- 解锁全部：解锁所有建筑、天赋、地块
- 无限资源：资源不减少
- 无限制升级：建筑升级不受等级限制

### 时间控制
- 时间加速：1x / 2x / 5x / 10x
- 时间暂停：冻结游戏时间
- 跳天：跳过指定天数
- 季节固定：锁定当前季节

### 高级工具
- 全部升级：所有建筑升级到顶级
- 全部完工：立即完成所有在建建筑
- 品阶晋升：逐级提升城市品阶
- 解锁成就：解锁所有 Steam 成就
- 灾害控制：清除/关闭各类灾害

### 存档管理
- 备份当前存档：一键备份整个存档目录
- 备份单个文件：备份指定存档文件
- 清理旧备份：删除所有备份（需二次确认）
- 打开存档目录：快速定位存档位置

## 安全提示

### 重要警告
1. **仅限单机使用**：本修改器仅用于单机游戏，禁止在联机/多人模式使用
2. **先备份存档**：使用修改功能前，强烈建议先备份存档
3. **可能导致崩溃**：部分功能可能导致游戏不稳定，使用前请保存游戏
4. **不支持云存档**：修改可能与 Steam 云存档冲突，建议关闭云同步

### 高危操作（需二次确认）
- 资源归零
- 开启全部作弊
- 全部升级 / 全部完工
- 解锁全部成就 / 地块 / 天赋
- 关闭全部灾害
- 清理旧备份

## 故障排查

### DLL 注入失败
**症状**：点击注入后提示失败
**排查步骤**：
1. 确认游戏已启动并进入游戏
2. 以管理员身份运行修改器
3. 检查杀毒软件是否拦截了 DLL
4. 确认游戏版本是否受支持（当前支持 Steam 版）

### 功能无效果
**症状**：点击功能按钮后游戏无变化
**排查步骤**：
1. 确认 DLL 已成功注入
2. 查看日志面板是否有错误信息
3. 确认游戏版本与修改器版本匹配
4. 尝试重新注入 DLL

### 游戏崩溃
**症状**：使用功能后游戏闪退
**排查步骤**：
1. 恢复备份存档
2. 减少同时开启的功能数量
3. 查看游戏日志（游戏目录/logs/core/）
4. 在监控页运行「一键系统诊断」

### Overlay 不显示
**症状**：按 INSERT 键无反应
**排查步骤**：
1. 确认 Overlay DLL 已注入
2. 确认游戏使用 DX11（当前仅支持 DX11）
3. 检查是否被其他 Overlay 软件冲突（如 Steam Overlay、MSI Afterburner）

### 热键不生效
**症状**：按热键无反应
**排查步骤**：
1. 确认 DLL 已注入
2. 检查热键是否与其他软件冲突
3. 在设置页重新配置热键
4. 确认热键防抖未拦截（连续快速按键会被忽略）

## 配置文件说明

配置文件位置：`%LOCALAPPDATA%\woldvein_trainer\config.json`

主要配置项：
- `game_path`：游戏安装路径
- `hotkeys`：热键映射
- `creative_mode`：创造模式子选项
- `theme`：UI 主题（dark/light）
- `window`：窗口位置和大小

---

## 数据目录

- **配置文件**：`%LOCALAPPDATA%\woldvein_trainer\config.json`
- **日志文件**：`%LOCALAPPDATA%\woldvein_trainer\logs\`
- **备份文件**：修改器目录下 `backups\`
- **预设文件**：修改器目录下 `presets\`

## 版本更新

### 自动更新
- 修改器启动时自动检查更新
- 发现新版本时提示下载
- 更新失败自动回滚到旧版本

### 手动更新
1. 下载最新版本压缩包
2. 关闭修改器
3. 解压覆盖到修改器目录（配置文件不会被覆盖）
4. 重新启动
