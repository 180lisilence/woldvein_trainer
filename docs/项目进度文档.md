## 一、项目概述

### 1.1 项目目标
为《平野孤鸿》(Steam AppID: 2656540) 开发一款功能完善的单机游戏修改器，支持资源修改、创意模式、存档管理、内存调试等功能。

### 1.2 技术栈
- **前端UI**：Python + tkinter（1897行）
- **核心逻辑**：Python（36个模块）
- **注入层**：C DLL（命名管道通信，164KB）
- **打包**：PyInstaller + Inno Setup
- **游戏引擎**：Unity + Il2Cpp

### 1.3 项目目录
```
woldvein_trainer0.4.6/
├── src/                    # 36个Python核心模块
├── assets/                 # 图标、资源
├── locales/                # 多语言翻译（zh-CN/en-US）
├── tests/                  # 单元测试（36个测试用例）
├── docs/                   # 文档
├── dist/                   # 打包输出（DLL + EXE）
├── trainer_ui_tk.py        # 主UI文件（1897行）
├── main.py                 # 入口
├── woldvein_trainer.spec   # PyInstaller配置
└── woldvein_trainer.iss    # Inno Setup安装脚本
```

## 三、核心模块详解

### 3.1 注入与通信层

| 模块 | 功能 | 关键技术 |
|------|------|----------|
| injector/__init__.py | 进程检测、DLL注入、白名单验证 | OpenProcess + CreateRemoteThread |
| 命名管道 | Python↔DLL双向通信 | `\\.\pipe\woldvein_trainer` |
| overlay_controller | 游戏内Overlay控制 | DX11 Present Hook + ImGui |

**通信流程：**
```
Python UI → 命名管道 → DLL → Lua引擎 → 游戏内存
                ↑                          ↓
                └────── 执行结果 ──────────┘
```

### 3.2 安全防护层

| 模块 | 功能 |
|------|------|
| input_validator | 数值范围校验（资源1-9999999、品阶1-14等） |
| address_validator | 内存地址合法性校验（范围、页状态、权限） |
| atomic_file | 文件原子写入（临时文件+rename） |
| emergency_stop | 一键终止全部内存写入/Hook/异步任务 |
| hotkey_debouncer | 热键防抖（普通200ms/高危500ms/一次性1000ms） |
| hotkey_conflict | 热键冲突检测（内部/系统/游戏） |

### 3.3 功能增强层

| 模块 | 功能 |
|------|------|
| preset_manager | 预设方案保存/加载/删除/导入/导出 |
| operation_history | 操作日志与撤销/重做（100条上限） |
| nonlinear_history | 非线性历史跳转、分支历史 |
| transaction | 事务批量操作（全部成功或全部回滚） |
| aob_scanner | AOB特征码扫描（支持??通配符） |
| lua_explorer | Lua环境探查（全局变量、表结构、函数信息） |
| diagnostic | 系统诊断（环境、状态、依赖检查） |
| auto_updater | 自动更新（GitHub Releases、SHA256校验、回滚） |

### 3.4 体验优化层

| 模块 | 功能 |
|------|------|
| i18n | 多语言（简体中文/英文，96条翻译） |
| theme_manager | 6种主题（暗色/亮色/午夜蓝/森林绿/日落橙/高对比度） |
| startup_optimizer | 启动优化（懒加载、并行初始化） |
| log_enhancer | 日志增强（5级、滚动、过滤、导出、统计） |
| process_handle_cache | 进程句柄缓存（避免频繁Open/Close） |
| config | 配置缓存+延时写入（500ms合并） |
| crash_report | 崩溃报告自动收集（系统信息+日志+配置+线程） |
